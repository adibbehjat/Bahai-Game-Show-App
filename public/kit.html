Question Kit

Write questions for the game and get ready-to-paste lines. Nothing you do on this page is sent anywhere; it makes no network requests.

  1. Copy the line(s).
  2. On the server, paste into questions/<pack-id>/questions.jsonl (one per line).
  3. Run npm run validate-questions.
  4. Restart the server (sudo systemctl restart game_show).
